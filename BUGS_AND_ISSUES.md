# Bugs and Issues Report

This document records the exact bugs, code vulnerabilities, configuration errors, and missing logic identified in the **FlareGit** project during our professional audit.

---

## Technical Defect Catalog

| ID | Severity | Area | Issue Description | Evidence / Location | Impact | Recommended Fix |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **BUG-01** | **Critical** | Backend API (Analytics) | `getServerSession()` called without `authOptions` in 5 different routes. | [contributions route](file:///j:/Saas/flaregit/src/app/api/github/contributions/%5Busername%5D/route.js#L7)<br>[languages route](file:///j:/Saas/flaregit/src/app/api/github/languages/%5Busername%5D/route.js#L7)<br>[stats route](file:///j:/Saas/flaregit/src/app/api/github/stats/%5Busername%5D/route.js#L7)<br>[traffic route](file:///j:/Saas/flaregit/src/app/api/github/traffic/%5Busername%5D/%5Brepo%5D/route.js#L7)<br>[trends route](file:///j:/Saas/flaregit/src/app/api/github/trends/%5Busername%5D/route.js#L7) | Access tokens are never retrieved from the JWT session. These endpoints always return a `401 Unauthorized (GitHub token not found)` error, breaking all dashboard charts and analytics. | Import `authOptions` from `@/lib/auth` and pass it to `getServerSession`:<br>`getServerSession(authOptions)` |
| **BUG-02** | **Critical** | Database / Config | The MongoDB cluster domain `flare-git.frcqa.mongodb.net` in the `.env` database URL does not exist. | [.env Line 2](file:///j:/Saas/flaregit/.env#L2) / DNS Lookup Test | The application fails to connect to the database and crashes during data fetching operations or testing. | Update `DATABASE_URL` with a valid, active MongoDB connection string. |
| **BUG-03** | **Critical** | Profile README Flow | The Profile README Editor has no Save button, and the Generator is imported but never rendered. | [dashboard/page.js Line 458-460](file:///j:/Saas/flaregit/src/app/dashboard/page.js#L458-L460) | Users cannot generate profile READMEs using AI, and manual changes made in the editor cannot be saved to the database. | Render the `ReadmeGenerator` in the tab or merge its button into the editor. Add a `PUT` request in `ReadmeEditor` to save the markdown code to `/api/profile/[userId]` and load `profile.generatedReadme` as the initial content state. |
| **BUG-04** | **High** | AI Bio Flow | "Generate with AI" button in the bio editor is static and has no action. | [dashboard/page.js Line 378](file:///j:/Saas/flaregit/src/app/dashboard/page.js#L378) | The AI professional bio feature is completely non-functional. | Create an API endpoint (`/api/ai/generate-bio`) that triggers OpenRouter/Gemini, and bind the button's `onClick` handler to call this endpoint. |
| **BUG-05** | **High** | Security / Routing | Collision risk in profile database queries by username. | [profiles/[username]/route.js Line 8-11](file:///j:/Saas/flaregit/src/app/api/profiles/%5Busername%5D/route.js#L8-L11) | If User A sets a `customUrl` matching User B's `githubUsername`, the query retrieves whichever profile MongoDB indexes first, allowing URL hijacking. | Validate that `customUrl` is not equal to any existing user's `githubUsername` or `customUrl` before updating. |
| **BUG-06** | **High** | Security / Auth | Exposed repository modification path without ownership checks. | [update-readme/route.js Line 34](file:///j:/Saas/flaregit/src/app/api/github/repositories/%5Busername%5D/%5Brepo%5D/update-readme/route.js#L34) | An authenticated user could theoretically post to this API and modify code/README files in repositories belonging to other users if they have collaborator rights or if credentials overlap. | Add a validation check: `if (session.user.username !== username) { return Forbidden; }` |
| **BUG-07** | **Medium** | Routing / UX | Dashboard is protected client-side via React state redirect. | [dashboard/page.js Line 58-62](file:///j:/Saas/flaregit/src/app/dashboard/page.js#L58-L62) | Displays the dashboard outline/skeleton to unauthorized users before redirecting, causing visual flickering. | Create a `src/middleware.js` to handle authentication checks on the server-side before serving `/dashboard`. |
| **BUG-08** | **Medium** | UI/UX | Duplicated Theme and Settings triggers on the dashboard tabs. | [dashboard/page.js Line 247-248](file:///j:/Saas/flaregit/src/app/dashboard/page.js#L247-L248) | Clicking the "Theme" tab trigger renders nothing since there is no `<TabsContent value="theme">` component defined. | Remove the extra `Theme` tab trigger, or rename the `settings` content tab to `theme` to align triggers and content. |
| **BUG-09** | **Low** | Code Quality | Unused imports in main dashboard page. | [dashboard/page.js Line 22-26](file:///j:/Saas/flaregit/src/app/dashboard/page.js#L22-L26) | Clutters the code and increases build bundle sizes. | Remove `RepositoryList`, `GitHubService`, and `ReadmeGenerator` imports since they are not used. |
| **BUG-10** | **Low** | Code Quality | Duplicate `use-toast.js` utility hook files. | `src/components/ui/use-toast.js`<br>`src/hooks/use-toast.js` | Violates the DRY (Don't Repeat Yourself) principle and leads to code inconsistency. | Keep `src/hooks/use-toast.js` (standard shadcn/ui React hooks folder) and delete the duplicate under `src/components/ui`. Update imports accordingly. |
| **BUG-11** | **Low** | Navigation | Landing page footer links point to missing pages. | [page.js Line 65-76](file:///j:/Saas/flaregit/src/app/page.js#L65-L76) | Clicking Privacy Policy or Terms of Service results in a 404 error page. | Create simple, static `/privacy/page.js` and `/terms/page.js` files. |
